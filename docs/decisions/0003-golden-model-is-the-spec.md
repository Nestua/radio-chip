# ADR 0003 — The golden model is the specification

Status: accepted · 2026-11-16

## Decision

The Rust model in `crates/radio-phy` (and later `radio-mac`) defines the exact bits the hardware
produces. Where the hardware uses fixed point, the model uses the same formats, rounding and
saturation. RTL is correct when it is bit-exact with the model on committed vectors (G3).

Word lengths are chosen by sweeping against a float model and accepting the smallest format whose
loss stays within the block's budget (G2). The float model is a tool for that sweep, not the spec.

## Consequences

- A disagreement between RTL and model is always investigated as a possible model bug too; the
  model is fixed first, vectors regenerated, then the RTL.
- Vectors are generated by `rvec` and committed; CI regenerates them and fails on any diff.
- Floating point in a fixed-point block's model is a bug.
