# rxagc loop: ADR 0008, decision 2, as a closed loop a sample at a time. 2000 frames of 1000 octets per row, the
# frames of `hold` (the same scenes); noise at -30 dBFS at the largest gain unless the row says, no DC offset unless the
# row says; clock offset uniform in ±40 ppm, carrier 5.8 GHz. Gain control: the AD9361's reset values with 16
# samples of power and the overload exit on (as every command), stepped with the receiver (FastAttackAgc::start).
# Receiver, all in integers, in every column: each ADC sample through the streaming front (RxHandoffFixed: 8 beats
# a period, the replay 20 periods after the declaration), the decoder as its reader: it sees the beats alone, gives
# SIGNAL's verdict (decode_signal_fixed on the stream's first 208 samples, with the stream's tag) 50 periods

# word) when its end mark comes. The front searches all through; a frame is received if any stream decodes to it.
# Phase jump per gain change uniform in ±30°.
# Who keeps the gain still:
#   from the lock    = held from the control's first lock inside the packet to the stream's end
#                      (the tool knows where the packet is: the assumption of the other commands' columns);
#   timer + front    = the control keeps every lock 512 samples, and the front's own hold (RxHandoffFixed::hold:
#                      from the declaration to the end SIGNAL's length gives, to the verdict when SIGNAL fails,
#                      to the longest PPDU's end with no verdict) holds the control from the sample after;
#   timer<max + front = the same, the timer keeping only a lock taken below the largest gain

#                      (RxHandoffFixed; the stream goes on, only a new declaration raises the hold again);
#   front + release +40 = the same with the hold acting 40 samples (2 µs) later, its release with it.
# The release is off in every column but the last two.
# A released control returns to the largest gain and searches (an assumption).
