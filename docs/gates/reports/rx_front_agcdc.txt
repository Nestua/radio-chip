# ±235 kHz, phase jump ±30° per gain change (assumed), 12-bit ADC, the float receiver
# (RxFront without its own blocker + rx_ofdm with its defaults) on the ADC's samples.
# DC per gain state: channel::GainDc, levels in dBFS at the ADC (0 dBFS = full-scale
# amplitude 1); 'per index' has that size at every gain with a direction per index,
# 'before the gain' has that size at the largest gain (73 dB) and falls with the gain.
# The gain control's detectors see the offset with the signal.
# Columns, the DC blocker (pole 2^-7): none = no blocker; free/raw = the blocker as it
# is before the acquisition, the decoder handed the samples before it (what rxper
# does); free = the decoder handed the blocker's output, as in all further columns;
# hold = estimate held from the first gain change to the lock; rescale = estimate
# scaled by each gain change; restart4 = gear restarted at 2^-4 at each change;
# hold+r4, hold+r6 = held, then restarted at 2^-4 or 2^-6 at the lock; freeze,
# r4+freeze = free or restart4, the estimate frozen from the sample at which the
# acquisition is declared (the decoder's stream; the acquisition sees the unfrozen).
# Each cell: frames lost (not decoded to the PSDU) / of those, not acquired with the
# exact timing. The gain is held from the first lock inside the packet (assumed: a
# hold driven by the receiver); held = frames in which it would otherwise have
# changed again before the packet's end.
